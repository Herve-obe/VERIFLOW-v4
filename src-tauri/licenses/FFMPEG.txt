FFmpeg intégré à VERIFLOW
=========================

VERIFLOW est livré avec les programmes ffmpeg et ffprobe (FFmpeg 9.0.2),
installés à côté de l'exécutable VERIFLOW sous les noms veriflow-ffmpeg et
veriflow-ffprobe. Ils sont exécutés comme des programmes séparés.

FFmpeg est un logiciel libre (https://ffmpeg.org). Les binaires livrés sont
compilés avec --enable-gpl --enable-version3, sans --enable-nonfree : ils sont
distribués sous licence GNU General Public License version 3 (texte complet :
LICENSE-GPL-3.0.txt, ou https://www.gnu.org/licenses/gpl-3.0.html). Chaque
bibliothèque compilée dedans garde sa propre licence, compatible avec la
GPLv3 (liste : COMPOSANTS_TIERS.md).

Origine des binaires
  Windows x64 : BtbN/FFmpeg-Builds, autobuild-2026-09-30-13-08,
                ffmpeg-n9.0.2-17-g2a571b6068-win64-gpl-9.0.zip
  Linux x64   : BtbN/FFmpeg-Builds, autobuild-2026-09-30-13-08,
                ffmpeg-n9.0.2-17-g2a571b6068-linux64-gpl-9.0.tar.xz
  macOS       : compilé par VERIFLOW (scripts/build-ffmpeg-macos.sh), FFmpeg
                9.0.2 et chaque bibliothèque à un commit épinglé.
La configuration exacte s'affiche dans VERIFLOW (Aide > Licences > FFmpeg)
ou avec « veriflow-ffmpeg -buildconf ».

Code source correspondant (GPLv3, article 6 d)
  Le code source complet de ces binaires (FFmpeg, chaque bibliothèque, les
  scripts et options de compilation) est joint à chaque version publiée de
  VERIFLOW, au même endroit que les installeurs :
    ffmpeg-sources-9.0.2-windows-linux.tar
    ffmpeg-sources-9.0.2-macos.tar
  Il reste disponible tant que la version correspondante est proposée au
  téléchargement.
